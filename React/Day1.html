React Study Guide
BEFORE THE TASKS

What is React?

React is a JavaScript library for building interactive user interfaces. It allows developers to build applications using reusable components and a declarative approach. React was originally created at Facebook to make complex and frequently changing user interfaces easier to develop and maintain.

01

React History & Background

Who created React?

React was originally created by Jordan Walke while he was working at Facebook.

When was React introduced?

React was developed internally at Facebook and was open-sourced publicly on May 29, 2013.

Why was React created?

As Facebook's applications became more complex and interactive, manually managing DOM updates became difficult. React was created to provide a simpler, declarative and component-based way to build UIs.

Problems React addresses

  • • Complex UI management
  • • Manual DOM manipulation
  • • Repeated UI code
  • • Difficult UI updates
  • • Keeping UI and data synchronized

TASK 1

React Basics

1. What is React?

React is a JavaScript library for building interactive user interfaces. It allows developers to create UI using reusable components and a declarative approach.

2. Why do we use React?

We use React to build interactive and dynamic user interfaces efficiently. It helps us divide the UI into reusable components and update only the parts that need to change.

3. Is React a library or framework?

React is a JavaScript library mainly focused on building the user interface. Other features such as routing and state management can be added using additional libraries.

4. What are the main features of React?

The main features of React include component-based architecture, JSX, declarative UI, Virtual DOM, one-way data flow, reusable components, props and state.

5. What is a Single Page Application (SPA)?

A Single Page Application is a web application where the browser initially loads one main HTML page and React dynamically updates the required UI without completely reloading the page for every navigation.

6. What is declarative UI?

Declarative UI means we describe what the UI should look like based on the current state or data, and React handles how the required DOM updates should happen.

TASK 2

Components

1. What is a Component in React?

A component is an independent and reusable piece of UI in a React application. It can contain its own UI and logic.

2. Why do we use Components?

Components help us divide a large UI into smaller parts, reuse UI in different places, make code easier to understand and make applications easier to maintain.

3. What is a Functional Component?

A functional component is a JavaScript function that returns JSX to describe a part of the user interface. 

function Welcome() {
    return <h1>Welcome</h1>;
}

4. What is Component-Based Architecture?

Component-based architecture means building an application by dividing the UI into small, independent and reusable components.

5. What is a Component Tree?

A component tree represents the parent-child relationship between components in a React application. 

App
 ├── Header
 ├── Main
 │    ├── ProductList
 │    └── ProductCard
 └── Footer

6. Why should component names start with a capital letter?

React uses the first letter to distinguish custom React components from normal HTML elements. For example, <Header /> is treated as a React component, while <header> is treated as an HTML element.

7. What is a reusable component?

A reusable component is a component that can be used multiple times in different places, often with different data passed through props.

TASK 3

JSX

1. What is JSX?

JSX stands for JavaScript XML. It is a syntax extension for JavaScript that allows us to write HTML-like UI code inside JavaScript. 

const element = <h1>Hello</h1>;

2. Why do we use JSX in React?

JSX makes UI code easier to read and write because we can write the structure of the UI close to the JavaScript logic that controls it.

3. Is JSX HTML?

No. JSX is not HTML. It is a syntax extension for JavaScript that looks similar to HTML and is processed by React into JavaScript and React elements.

4. How do we write JavaScript expressions inside JSX?

JavaScript expressions are written inside curly braces. 

const name = "Faitha";

return <h1>Hello {name}</h1>;

5. Why do we use className instead of class?

JSX uses className instead of class because class is a JavaScript keyword. className represents the HTML class attribute in JSX.

6. What is React Fragment?

A React Fragment allows us to group multiple JSX elements without adding an extra HTML element to the DOM. 

<>
    <h1>Hello</h1>
    <p>Welcome</p>
</>

7. What are the important JSX rules?

  • • JSX should have one parent element or Fragment.
  • • Use className instead of class.
  • • JavaScript expressions are written inside {}.
  • • Tags must be properly closed.
  • • JSX attributes often use camelCase.
  • • Component names should start with a capital letter.
TASK 4

DOM, Virtual DOM & Reconciliation

1. What is DOM?

DOM stands for Document Object Model. It is the browser's representation of an HTML document as a tree of objects or nodes that JavaScript can access and modify.

2. What is Virtual DOM?

The Virtual DOM is a lightweight JavaScript representation of the UI that React uses to determine what changes are needed in the actual DOM.

3. What is the difference between DOM and Virtual DOM?

DOM Virtual DOM
Browser's actual UI representation JavaScript representation of UI
Directly affects browser UI Helps React calculate changes
Part of browser Managed by React

4. What is Reconciliation in React?

Reconciliation is the process React uses to compare the previous UI representation with the new one and determine what needs to change in the actual DOM.

5. What is Diffing?

Diffing is the comparison process where React compares the previous and new UI representations to find differences.

6. How does React identify changes in the UI?

React compares the previous React element tree with the new React element tree. It uses element types, positions and keys for list items to determine what has changed.

7. Why is key important while rendering lists?

A key gives each list item a stable identity. React uses keys to identify which items have changed, been added, removed or reordered. 

students.map(student => (
    <Student key={student.id} />
))
TASK 5

React Rendering Process

Complete Flow

Component → JSX → Rendering → UI Representation → State / Props Change → Re-render → Reconciliation → Diffing → DOM Update → Browser UI

1. What is Rendering?

Rendering is the process where React runs a component and calculates what the UI should look like based on its current props and state.

2. What is Re-rendering?

Re-rendering means React runs a component again to calculate its updated UI after something relevant, such as state or props, changes.

3. What causes a component to re-render?

A component can re-render when its state changes, its props change, its parent re-renders, or a subscribed context value changes.

4. Does re-render mean the complete browser DOM is recreated?

No. Re-rendering does not mean that the complete browser DOM is destroyed and recreated. React calculates the new UI representation and determines which parts of the actual DOM need to be updated.

5. What happens during reconciliation?

React creates a new UI representation, compares it with the previous one, identifies the differences, determines the required DOM changes and applies those changes to the browser.

6. What is the relationship between Virtual DOM, Diffing and Reconciliation?

The Virtual DOM represents the UI. When the UI changes, React creates a new representation and compares it with the previous one. This comparison is called diffing, and it is part of the reconciliation process. React then determines the required changes to the actual DOM.

7. Explain the React rendering process in your own words.

First, React runs the component and creates a representation of what the UI should look like. When state or props change, the component may render again and produce a new UI representation. React then compares the new representation with the previous one. This comparison is part of reconciliation and involves diffing. React identifies the required changes and updates only the necessary parts of the actual DOM. The browser then displays those changes to the user.
