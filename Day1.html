My Understanding of JavaScript

JavaScript is a programming language that adds logic, interaction and dynamic behavior to a webpage, rather than keeping it limited to static HTML and CSS.

When JavaScript runs, I understand that it first creates memory for variables and functions and then executes the code step by step.

Variables store values, while data types define what kind of data we are working with, and operators help us perform operations on that data.

Using conditions like if-else and switch, JavaScript can make decisions, while functions allow us to organize and reuse a particular piece of logic.

Since JavaScript is dynamically typed, a variable can hold different types of values during execution, and type conversion can happen either automatically or explicitly.

Scope determines where a variable is accessible, which helps control how data is used within different parts of a program.

The important part for web development is the DOM, through which JavaScript can access HTML elements and change their content, properties or styling while the page is running.

So, from my understanding, JavaScript connects data, logic, decision-making and the webpage together to turn a static page into an interactive and dynamic application.

Expressions and Statements

Expressions

An expression is a piece of JavaScript code that produces or evaluates to a value. It can be used wherever JavaScript expects a value.

Examples of Expressions

10 + 20

age + 5

10 > 5

"Hello" + name

isLoggedIn && isActive

Example

let result = 10 + 20;

Here, 10 + 20 is an expression because it produces the value 30.

Statements

A statement is a complete instruction given to JavaScript to perform an action. A program is generally made up of multiple statements.

Examples of Statements

let age = 20;

console.log(age);

age = 25;

if (age >= 18) { console.log("Eligible"); }

Example

let result = 10 + 20;

Here, the complete line let result = 10 + 20; is a statement because it gives JavaScript an instruction to create the variable and assign a value to it.

Difference Between Expression and Statement

Expression: Produces a value

Example: 10 + 20 produces 30.

Statement: Performs an instruction

Example: let result = 10 + 20; creates a variable and assigns the calculated value to it.
